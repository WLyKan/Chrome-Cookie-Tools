# Storage Dev Tools Context Index

## Project Snapshot

Storage Dev Tools 是一个面向开发者的 Chrome 浏览器扩展，用于在开发/测试/生产环境之间快速传输 Cookie 或 LocalStorage 数据。项目使用 WXT + React + TypeScript 技术栈，已完成核心功能实现。

## How To Use This Directory

- `project.md`: 项目定位、用户、架构、技术栈和工程假设
- `rules.md`: Agent 执行规则和工作流约定

- `changes/`: 活跃的工作进行中
